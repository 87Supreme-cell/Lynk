# Architecture decision records

Use this directory for decisions that will matter after the implementation that
introduced them is no longer fresh. Do not create an ADR for routine refactors.

## Naming

Use zero-padded, sequential filenames:

```text
0001-local-first-storage.md
0002-approval-gated-rag.md
```

## Template

```md
# ADR NNNN: Short decision title

**Status:** proposed | accepted | superseded

## Context

What problem, constraint, or requirement requires a decision?

## Decision

What will Lynk do?

## Alternatives considered

What credible options were considered and why were they not selected?

## Consequences

What does this make easier, harder, or mandatory?
```
